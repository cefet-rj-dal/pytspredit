# NN3 monthly business series (`datasets.nn3`)

**About the dataset**

* `datasets.nn3()` returns the Eidolon **miniature** -- a data frame (one column per series / interval) -- numerically identical to the R package. The full artifact is resolved on demand with `datasets.loadfulldata`.

**Didactic goal:** load and inspect the dataset's structure.

```python
import warnings
warnings.filterwarnings("ignore")

import pytspredit as ts
```

```python
d = ts.datasets.nn3()
print("shape:", d.shape)
d.head(3)
```

```python
ts.datasets.dataset_url("NN3")   # full artifact (loadfulldata)
```

> **What to observe.** The miniature preserves the schema of the full dataset (same columns/keys); use `loadfulldata` to fetch the complete series.

**References:** Crone, Hibon & Nikolopoulos (2011), Int. J. Forecasting, 27(3), 635-660.
