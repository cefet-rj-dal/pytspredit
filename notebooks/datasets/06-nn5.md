# NN5 daily ATM withdrawals (`datasets.nn5`)

**About the dataset**

* `datasets.nn5()` returns the Eidolon **miniature** -- a data frame (one column per series / interval) -- numerically identical to the R package. The full artifact is resolved on demand with `datasets.loadfulldata`.

**Didactic goal:** load and inspect the dataset's structure.

```python
import warnings
warnings.filterwarnings("ignore")

import pytspredit as ts
```

```python
d = ts.datasets.nn5()
print("shape:", d.shape)
d.head(3)
```

```python
ts.datasets.dataset_url("NN5")   # full artifact (loadfulldata)
```

> **What to observe.** The miniature preserves the schema of the full dataset (same columns/keys); use `loadfulldata` to fetch the complete series.

**References:** Crone (2008), *Results of the NN5 Competition*, IEEE WCCI.
