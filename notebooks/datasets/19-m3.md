# M3 competition series (`datasets.m3`)

**About the dataset**

* `datasets.m3()` returns the Eidolon **miniature** -- a dict (by frequency) of dicts of series -- numerically identical to the R package. The full artifact is resolved on demand with `datasets.loadfulldata`.

**Didactic goal:** load and inspect the dataset's structure.

```python
import warnings
warnings.filterwarnings("ignore")

import pytspredit as ts
```

```python
d = ts.datasets.m3()
freq = list(d)[0]
print("frequencies:", list(d), "| series in", freq, ":", list(d[freq])[:3])
next(iter(d[freq].values())).head()
```

```python
ts.datasets.dataset_url("m3")   # full artifact (loadfulldata)
```

> **What to observe.** The miniature preserves the schema of the full dataset (same columns/keys); use `loadfulldata` to fetch the complete series.

**References:** Makridakis & Hibon (2000), Int. J. Forecasting, 16(4), 451-476.
