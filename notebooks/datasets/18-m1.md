# M1 competition series (`datasets.m1`)

**About the dataset**

* `datasets.m1()` returns the Eidolon **miniature** -- a dict of data frames -- numerically identical to the R package. The full artifact is resolved on demand with `datasets.loadfulldata`.

**Didactic goal:** load and inspect the dataset's structure.

```python
import warnings
warnings.filterwarnings("ignore")

import pytspredit as ts
```

```python
d = ts.datasets.m1()
print("keys:", list(d))
next(iter(d.values())).head(3)
```

```python
ts.datasets.dataset_url("m1")   # full artifact (loadfulldata)
```

> **What to observe.** The miniature preserves the schema of the full dataset (same columns/keys); use `loadfulldata` to fetch the complete series.

**References:** Makridakis et al. (1982), J. Forecasting, 1(2), 111-153.
