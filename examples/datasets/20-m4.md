# M4 competition series (`datasets.m4`)

**About the dataset**

* `datasets.m4()` returns the Eidolon **miniature** -- a dict (by frequency) of dicts of series -- numerically identical to the R package. The full artifact is resolved on demand with `datasets.loadfulldata`.

**Didactic goal:** load and inspect the dataset's structure.


```python
import warnings
warnings.filterwarnings("ignore")

import pytspredit as ts
```


```python
d = ts.datasets.m4()
freq = list(d)[0]
print("frequencies:", list(d), "| series in", freq, ":", list(d[freq])[:3])
next(iter(d[freq].values())).head()
```
